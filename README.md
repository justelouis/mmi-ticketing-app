# 🎟️ Simple Ticketing System Website

A functional web application for event ticketing, built as a practical project during my 1st year of **BUT MMI** (IUT de Rouen). 

> **Note:** The core objective of this project was to master web development logic, database interactions, and overall functionality. As the emphasis was placed entirely on architecture and dynamic features, the user interface remains minimal.

---

## 💡 Project Overview

This project serves as a hands-on exercise to practice full-stack dynamic web development. It covers the essential flow of a ticketing platform, from browsing available events to handling seat selection, dynamic data persistence, and managing user bookings.

### Key Features
- 📅 **Event Browsing:** View upcoming events dynamically fetched from the database.
- 🎟️ **Ticket Reservation:** Select tickets and process simulated bookings.
- 👤 **User Management:** Custom user authentication with domain-restricted registration and session management.
- 🗄️ **Database Operations:** Real-time updates on ticket availability and user reservations via SQL queries.
